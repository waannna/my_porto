##  Architectural & Design Highlights

- **Brutalist Newspaper Aesthetic:** Inspired by classic broadsheet journalism (*The Digital Chronicle*) featuring paper beige backgrounds (`#fbf9f5`), solid 2px black borders, hard-edged offset drop shadows, and serif headline typography.
- **Mobile-First Responsive Engineering:** Precision layout tuned for Android and mobile screens (360px–430px) without awkward line wrapping or horizontal overflow.
- **Case Study Technical Dossiers:** Interactive modals with architectural highlights, system specifications, and embedded digital thermal POS settlement receipts.
- **Strict Clean UI:** Zero AI-slop, clean visual hierarchy, keyboard navigation shortcuts (`1-6` for instant section scrolling), and high accessibility standards.

##  Local Development Setup

Ensure you have **Node.js** (v18+) and **pnpm** installed on your system.

```bash
# 1. Clone this repository
git clone https://github.com/waannna/my_porto.git

# 2. Navigate to project directory
cd my_porto

# 3. Install dependencies using pnpm
pnpm install

# 4. Start local development server
pnpm dev
